# 安全消息原生转发

微信 8.0.77 的 `MsgRetransmitUI` 会在转发页创建后，把图片、视频、表情和 AppMsg 交给异步发送任务；这些任务通常会重新创建消息对象，不能依赖源消息对象自动继承 `msgSource`。

安全消息功能在 `onCreate(Bundle)` 和已确认的单字符串发送分派方法 `E6(String)` 两个边界建立短时转发上下文。上下文按收件人列表匹配，收件人尚未写入消息对象时使用一次性过期预算；最终消息入库或写入 `msgSource` 前补入 `sec_msg_node`。转发页面和微信原生成功提示不被拦截，接收方仍按安全消息规则处理。

本实现已根据 8.0.77(3160) 静态 APK 的 `Retr_Msg_content`、`Retr_Msg_content_bytes`、`Retr_Msg_Id`、`Retr_Msg_Id_List` 和 `MsgRetransmitUI.E6(String)` 证据编写；图片、视频、表情和卡片的接收方不可见效果仍需在对应设备上用新构建包实测。
